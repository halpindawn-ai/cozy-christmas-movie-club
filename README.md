# The Cozy Christmas Movie Club 🎄

Your 2026 holiday movie marathon starts here!

I used AI to build a ridiculously festive spreadsheet featuring 85+ new Christmas movies from Hallmark, Netflix, Lifetime, Prime Video, and more.

### What's included
- New holiday movie premieres for 2026
- Streaming platforms and release dates
- Watch-status tracker
- Personal ratings and notes
- Plenty of Christmas cheer

### How to use it

1. Download the Excel spreadsheet from this repository.
2. Open it in Excel or upload it to Google Sheets.
3. If using Google Sheets, select **File → Make a copy** to create your own version.
4. Start watching!

Happy holiday movie season!
